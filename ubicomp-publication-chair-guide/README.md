# UbiComp Publication Chair Guide

Static website prepared for Longfei Shangguan's personal homepage.

## Add it to the homepage

1. Copy this entire folder into the root of the `shanggdlk.github.io` repository.
2. Keep the folder name `ubicomp-publication-chair-guide` so the configured social-preview links remain correct.
3. Commit and push the folder.
4. The page will be available at:
   https://shanggdlk.github.io/ubicomp-publication-chair-guide/

The site is fully static and does not require Node.js, React, a database, or a server process.
